# 江戸幕府末期の銃撃戦.io

ブラウザで遊べる撃ち合いゲームです（Three.js + Socket.IO）。

## スマホだけでデプロイする（GitHub + Fly.io）

このフォルダには**サブフォルダがありません**。全ファイルを、GitHubリポジトリの**一番上**に置いてください。

1. zipを解凍する
2. GitHubのリポジトリで「Add file → Upload files」を開き、解凍した**ファイルをすべて選んで**アップロード → Commit
   （同じ名前のファイルは上書きされます。古い `client/` などのフォルダが残っていても問題ありません）
3. リポジトリの一番上に、次のファイルが並んでいるか確認する
   - `Dockerfile` `fly.toml` `package.json` `package-lock.json`
   - `index.html` `server.js` `shared-game.js`
   - `client-main.js` `client-view.js` `client-audio.js` `client-admin.js` `client-settings.js`
   - （`*.test.js` と `README.md` は上げなくても動きます。`.dockerignore` `.gitignore` は隠しファイルなので、上げられなくても大丈夫です）
4. Fly.io のダッシュボードから、このリポジトリをデプロイする（`fly.toml` の `app` は `studious-disco`。別の名前にしたい場合は書き換える）
5. 管理者になりたい場合は、Fly.io の Secrets に `ADMIN_KEY`（長い文字列）を登録する。ゲームの設定（Oキー／右上の歯車）の「管理者キー」に同じ文字列を入れる

### ビルドが失敗した時
ログの `ERROR:` で始まる行を見てください。

| 表示 | 意味と直し方 |
|---|---|
| `missing files: ...` | 書かれたファイルが上がっていません。リポジトリの一番上に上げる |
| `index.html is an OLD version` | 新しい `index.html` に置き換える |
| `package.json is OLD` | 新しい `package.json` と `package-lock.json` に置き換える |
| `SMOKE TEST FAILED` | サーバーが起動できません。その下に出るログを確認する |

## PCで動かす
```
npm install
npm run server   # ゲームサーバー（ポート3000）
npm run dev      # 画面（http://localhost:5173）
```
テスト：`npm test`（ルール・設定の単体テストと、実際にサーバーを起動して複数クライアントで動かす統合テスト）

## 操作
- PC：WASD移動 / Space ジャンプ / マウス視点 / クリック射撃 / 右クリック リープ（クールダウン2秒）/ 1〜9・Q/E・ホイールで武器 / R リロード / Tab スコア / O 設定 / V 投票キック（Y 賛成・N 反対）
- スマホ（横向き）：左のスティックで移動、画面のドラッグで視点、右下の「撃つ」ほかのボタン、右上の「投票」「⚙」。投票は画面上の「賛成」「反対」ボタンで入れる

## 武器・スキン
武器10種（ナイフ・ピストル・リボルバー・サブマシンガン・アサルトライフル・スナイパー・ショットガン・ヘビーライフル・デリンジャー・軽機関銃）、スキン21種（設定で武器ごとに選べる。相手にも見える）。

## 投票キック
3人以上で、投票で他のプレイヤーを切断できます（1件ずつ、30秒、対象以外の過半数が賛成で成立）。管理者は対象外。BANではありません。

## 管理者
管理者パネル（Pキー／右上の「管」）：キック、回復、凍結、呼び寄せ、移動、復活、マップ変更、お知らせ、操作ログ。

## 不正対策
- 移動・射撃・当たり判定はすべてサーバー側で計算します
- 入力の頻度・値の範囲を検査し、接続元のドメインも確認します
- エイムボットの疑いは自動検知し、段階的に処分します（1時間→2時間→5時間→10時間→永久BAN）
- 処分はブラウザごとの識別子単位です（同じIPの別の人を巻き込まないため）。同じIPから3つ以上の識別子が処分された時だけ、そのIPを1時間止めます
- 管理者キーはブラウザに保存しません（ページを開くたびに入力します）

## 処分の記録を再起動後も残す（任意）
処分の記録は `DATA_FILE`（既定 `data/penalties.json`）に保存されます。Fly.io で再起動後も残すには、**先に**ボリュームを作ります。
```
fly volumes create penalty_data --size 1 --region nrt
```
そのあと `fly.toml` に次を足し、`[env]` に `DATA_FILE = "/data/penalties.json"` を書きます。ボリュームを作る前に足すと、デプロイが失敗します。
```
[[mounts]]
  source = "penalty_data"
  destination = "/data"
```
